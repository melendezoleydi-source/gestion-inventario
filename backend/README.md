# API Inventario

API REST para la gestión de un sistema de inventario.

## Tecnologías

- NestJS
- TypeScript
- Prisma
- PostgreSQL
- Swagger

## Módulos

- Productos
- Categorías
- Marcas
- Proveedores
- Movimientos
- Clientes
- Ventas
- Detalle de venta
- Roles
- Usuarios
- Almacén

## Funcionalidades

La API permite realizar operaciones CRUD:

- Crear registros
- Listar registros
- Buscar registros por ID
- Actualizar registros
- Eliminar registros

## Ejecución del proyecto

Instalar dependencias:

npm install

Ejecutar en modo desarrollo:

npm run start:dev

Compilar el proyecto:

npm run build

Ejecutar en producción:

npm run start:prod
